# Samples

Small test files to try Cairn on without the game's data. Every file here is generated by a tool in `tools/`,
except the sample table, which is written by hand; none of them comes from the game, and none of them is a game
asset.

| Folder | What it holds |
|---|---|
| `atx/` | Animated textures. `hazard_strip.atx` is a clean eight-frame strip with its `hazard_strip_00.tga` to `hazard_strip_07.tga` frames and an alpha mask (`hazard_strip_mask.tga`). `broken_example.atx` is wrong on purpose: open it to see the Problems panel and its quick fixes. `dxt_pulse_00.dds` and `dxt_pulse_01.dds` are a pair of DXT1 frames, and `wrong_size_32.tga` is a frame of the wrong size for the frame-size check. Regenerate with `dotnet run --project tools/Cairn.Atx.SampleGen -- samples/atx`. |
| `rfa/` | A small made-up character (`sample_figure.v3c` with its texture) and clips for it: an idle, a walk, a wave meant to play as an action, and a deliberately broken clip. [rfa/README.md](rfa/README.md) describes each file and every problem the broken clip has. Regenerate with `dotnet run --project tools/Cairn.Rfa.SampleGen -- samples/rfa`. |
| `vfx/` | Will hold generated effects for the Effects module. |
| `tbl/` | `weapons.tbl`, a small made-up weapons table in the game's syntax for the Tables module: three weapons whose textures and mesh are the samples in `atx/` and `rfa/` (add those folders as search folders so the previews find them). Open it with **File › Open…**; do not add `tbl/` itself as a search folder, or Cairn will read it in place of the game's own `weapons.tbl`. |

To use the samples with the library panels, add this folder (or one of its subfolders) as a search folder under
**Tools › Settings…**.
